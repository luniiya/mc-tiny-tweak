MC Tiny Tweak

My opinionated Minecraft setup with all my favorite mods and tweaks in one place.

Damage numbers: hits show gacha-style floating numbers that get flashier the bigger they are, with a combo counter for your hits in a row and green numbers for heals. Every effect can be turned off under Tweaks, Damage numbers.

Install with Prism Launcher: create a Fabric instance for Minecraft 1.21.11, add Fabric API and Fabric Language Kotlin from the Mods page, then add the mc-tiny-tweak jar with Add file.

Credits: damage numbers use the Lilita One font by Juan Montoreano, under the SIL Open Font License, bundled with the mod.
